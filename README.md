# 全栈诊断台 · Full-Stack Diagnostic Bench

一个面向「用 AI 写代码、但要自己掌握系统架构」的练习工具。不教你怎么敲代码,而是练两件事:**遇到故障能定位到哪一层,以及知道接下来该怎么修。**

在线使用 → https://kelvinyim99.github.io/ai-/

## 两种练习模式

### 场景诊断 · 92 个真实故障案例

给一段真实的故障现象(报错信息、异常表现),判断根因,然后给出可执行的排查与修复步骤。

分 13 类,可按类筛选,支持错题本:

| 分类 | 数量 | 分类 | 数量 |
|---|---|---|---|
| 进程/端口 | 5 | Git/协作 | 7 |
| 环境/依赖 | 8 | 构建/部署 | 8 |
| 网络/DNS | 6 | 缓存/性能 | 7 |
| CORS/跨域 | 5 | 安全 | 7 |
| HTTP/接口 | 9 | 综合排查 | 5 |
| 前端/渲染 | 9 | | |
| 认证/权限 | 7 | | |
| 数据库 | 9 | | |

覆盖的高频坑包括:端口被占用、`command not found` 与 PATH、锁文件没提交导致版本不一致、Linux 区分文件名大小写、CORS 预检失败、用 `no-cors` 的假修复、401 vs 403、502 vs 504、SPA 刷新子路由 404、列表 key 用下标导致错位、刷新掉登录态、跨站 Cookie 丢失、越权访问、N+1 查询、缺索引、连接池耗尽、库存超卖、死锁、金额用浮点数、合并冲突、密钥误提交、容器起来就退出、缓存雪崩与穿透、SQL 注入、XSS 等。

### 架构蓝图 · 24 张图纸

每张图纸都是一个完整案例:先给**情景**,再让你把链路图补全,做对后给出**这张图能帮你诊断什么**。

包含基础链路(请求链路、计算机模型、运行时、后端分层、数据库关系、电商全景)与专门的排查链路(CORS 流程、登录态、部署链路、HTTP 状态码决策树、慢查询四条排查路径、缓存读写、文件上传、Git 四区域、依赖安装、Docker、CI/CD、状态更新、超时重试、密码链路、输入安全关卡)。

## 特点

- **纯静态单文件**,无构建、无依赖、无后端,双击 `index.html` 即可运行
- 进度存在浏览器本地,刷新不丢失
- 支持浅色/深色主题,自动跟随系统
- 键盘操作:`←` `→` 切题,数字键 `1-4` 或字母键 `A-D` 选答案
- 所有交互元素均为原生按钮,可键盘访问

## 本地运行

直接用浏览器打开 `index.html`,或起一个静态服务:

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000
